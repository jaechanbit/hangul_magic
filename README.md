# 🏛️ 공공 한글 기획·보고서 AI 메이커 (`hangul_magic`)

- **웹 바로가기**: https://jaechanbit.github.io/hangul_magic/

올린 한글(`.hwpx`, `.hwp`) 양식의 **글꼴·제목 상자·표 테두리·여백·머리말 디자인을 100% 그대로 유지**하면서, 쓰시는 AI(ChatGPT·Claude·Gemini 등)에 **복사·붙여넣기(API 비용 0원, 외부 서버 문서 전송 0%)** 방식으로 공공기관 기획서·보고서를 완성하는 웹 애플리케이션입니다.

## ✨ 주요 특징 및 현업 특화 기능

1. **공공기관 6대 문서 유형 특화 프롬프트 & 5대 표준 양식 내장**:
   - `사업 기획·추진계획(안)` / `추진실적·결과보고서` / `현안 검토·대책보고` / `예산 요구·산출내역서` / `회의록·간담회 결과` / `양식 자동 맞춤`
   - 별도 양식 파일이 없어도 바로 시작할 수 있는 **공공기관 5대 표준 양식(`.hwpx`)** 기본 내장
2. **참고·근거 자료 로컬 파서 대폭 확장 (`.hwpx`, `.hwp`, `.xlsx`, `.docx`, `.pdf`, `.csv`, `.txt`)**:
   - 브라우저 내부(Pyodide + lxml)에서 엑셀 예산 산출표(`.xlsx`), 워드 문서(`.docx`), PDF 지침서(`.pdf`), 한글 문서의 본문과 표 데이터를 추출하고 개인정보까지 자동 마스킹하여 근거자료로 활용
3. **내 기관·부서·기안자 기본 프로필 고정 & 작업 자동 임시저장**:
   - 기관명, 부서·팀명, 담당자 직급·성명, 연락처를 한 번 입력해 두면 표지·머리글(`@바꾸기`)과 담당자 칸에 자동 반영(성명·연락처도 AI 프롬프트에서는 자동 마스킹)
   - 작성 중인 요청사항과 초안을 브라우저에 자동 임시저장하여 실수로 새로고침하거나 창을 닫아도 원클릭 복구 지원
4. **공공기관 망분리(업무망 ↔ 인터넷망) 브리지 지원**:
   - 클립보드 공유가 제한된 망분리 환경을 위해 **마스킹 완료 프롬프트 `.txt` 파일 저장(반출)** 및 **AI 답변 `.txt` 파일 불러오기(반입)** 지원
5. **4단계 실시간 편집기 & 행정업무 운영 규정 원클릭 자동 교정**:
   - **📏 공문서 표기법 원클릭 자동 교정**: AI 재호출 없이 날짜(`2026. 11. 9.(월)`), 시각(`14:00`), 금액·수치 천 단위 쉼표(`4,800,000원`), 마크다운 잔재를 1초 만에 일괄 교정
   - **① 빈칸(`○○`) 및 서식 전체 항목 채우기**: 서식형 양식(`fill` 모드)에서도 내부 코드(`T2.3.1`) 대신 실제 한글 항목명을 라벨로 표시하며 전체 입력 칸 펼치기 지원
   - **② 원문 직접 편집기 & ③ AI 추가 수정**: 고정 표 셀 넘침(`res.over`) 자동 감지 경고 및 원클릭 분량 축약 요청 지원
6. **100% 브라우저 내부(WASM) 처리 & 개인정보 자동 마스킹**:
   - `Pyodide (Python 3 + lxml)` + `rhwp (Rust WASM)` 엔진으로 외부 서버 전송 없이 로컬 브라우저에서 동작

## 🚀 실행 및 배포 방법
- **로컬 PC에서 실행**: `run.bat`을 더블클릭하거나 터미널에서 `python -m http.server 8080` 실행 후 `http://127.0.0.1:8080` 접속
- **GitHub Pages / 사내 웹서버 배포**: 별도 빌드 과정 없이 이 폴더 전체를 정적 웹 서버나 GitHub Pages에 그대로 업로드하면 즉시 동작합니다.
