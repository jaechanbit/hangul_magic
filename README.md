# 🏛️ 공공 한글 기획·보고서 AI 메이커 (`gov-hwp-maker`)

올린 한글(`.hwpx`, `.hwp`) 양식의 **글꼴·제목 상자·표 테두리·여백·머리말 디자인을 100% 그대로 유지**하면서, 쓰시는 AI(ChatGPT·Claude·Gemini 등)에 **복사·붙여넣기(API 비용 0원, 외부 서버 문서 전송 0%)** 방식으로 공공기관 기획서·보고서를 완성하는 웹 애플리케이션입니다.

## ✨ 주요 특징 및 개선점
1. **공공기관 6대 문서 유형 특화 프롬프트**:
   - `사업 기획·추진계획(안)` / `추진실적·결과보고서` / `현안 검토·대책보고` / `예산 요구·산출내역서` / `회의록·간담회 결과` / `양식 자동 맞춤`
   - 양식 파일이 없어도 바로 시작할 수 있는 **공공기관 표준 양식 2종(사업추진계획서 / 결과보고서)** 기본 내장
2. **⚡ 1회 복붙 직행 모드 & 💬 역질문 정밀 설계 모드**:
   - **1회 복붙 직행 모드**: AI 역질문 없이 단 한 번의 복사·붙여넣기만으로 즉시 한글 파일 완성
   - **역질문 정밀 설계 모드**: AI가 부족한 핵심 정보(0~4개)를 물어보고 추천 초안과 함께 정밀 작성
3. **4단계 실시간 3종 편집기 (AI 재호출 없이 1초 반영)**:
   - **① 빈칸(`○○`) 빠른 채우기**: AI가 지어내지 않고 비워 둔 수치·일정만 모아 바로 입력
   - **② 원문 직접 편집기**: 개요 문법(`@제목:`, `[소제목]`, `□`, `○`, `[표] ... [/표]`)이나 서식 칸 값을 화면에서 직접 고쳐 1초 만에 한글 파일(`.hwpx` / `.hwp`)과 미리보기 갱신
   - **③ AI 추가 수정**: 분량 조절이나 내용 보강 프롬프트 생성 및 이전 상태 되돌리기(Undo)
4. **100% 브라우저 내부(WASM) 처리 & 개인정보 자동 마스킹**:
   - `Pyodide (Python 3.13 + lxml)` + `rhwp (Rust WASM)` 엔진으로 서버 없이 로컬 브라우저에서 동작
   - 이름·연락처·이메일·계좌번호·주민번호 등을 `[이름1]`, `[전화1]`로 가린 뒤 AI에 보내고, 완성 문서에서 원래 값으로 복원

## 🚀 실행 및 배포 방법
- **로컬 PC에서 실행**: `run.bat`을 더블클릭하거나 터미널에서 `python -m http.server 8080` 실행 후 `http://127.0.0.1:8080` 접속
- **GitHub Pages / 사내 웹서버 배포**: 별도 빌드 과정 없이 이 폴더 전체를 정적 웹 서버나 GitHub Pages에 그대로 업로드하면 즉시 동작합니다.
