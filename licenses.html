오픈소스 소프트웨어 라이선스 고지

공공 한글 기획·보고서 AI 메이커 (hangul_magic)는 모든 문서 분석·조립·변환·미리보기 처리를 사용자 브라우저 내부(WebAssembly)에서 안전하게 수행하기 위해 아래의 오픈소스 라이브러리를 사용합니다.

1. Pyodide (MPL-2.0)

  • 용도: 브라우저 내 Python 3 WebAssembly 런타임 구동 (engine/hwpdoc.py, engine/extra.py 실행)
  • 라이선스: Mozilla Public License 2.0 (MPL-2.0)
  • 출처: https://github.com/pyodide/pyodide

2. lxml / libxml2 / libxslt (BSD-3-Clause / MIT)

  • 용도: HWPX(OWPML) XML 및 XLSX·DOCX 문서 고속 파싱·조립
  • 라이선스: BSD 3-Clause License (lxml), MIT License (libxml2, libxslt)
  • 출처: https://lxml.de/

3. @rhwp/core (MIT / Apache-2.0)

  • 용도: 구형 한글(.hwp) ↔ 개방형 한글(.hwpx) 양방향 변환 및 SVG 페이지 미리보기 렌더링 (lib/rhwp/)
  • 라이선스: MIT / Apache-2.0

4. 한글 척척 (hangul-chukchuk) 기반 엔진 참고

  • 설명: 본 프로젝트의 HWPX 분석·조립 엔진(hwpdoc.py) 및 개인정보 마스커(lib/masker/core.js) 구조는 오픈소스 프로젝트 hangul-chukchuk의 클라이언트 로컬 처리 아키텍처를 기반으로 공공기관 기획·보고서 행정 실무에 맞게 확장·보강되었습니다.
